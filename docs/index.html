Before a coding agent flips, re-weights or archives a Flagsmith flag, it maps the blast radius: environments, overrides, running experiments, code and CI gates. It shows a one-screen plan and waits for a human. Then it applies, verifies and journals the change to git. If it was a mistake, undo is plain bash. No agent, no tokens.

Blast-radius graph

Edges for experiments, overrides, code references, CI gates and co-located flags, walked breadth-first in awk. It's the same idea as a Pregel-style propagation, without a framework.

Scored, explainable risk

NOOP · BLOCKED · HIGH · MEDIUM · LOW, from a handful of rules anyone can read in RISK.md.

Approval the agent can't fake

Protected environments need the human to type the environment name. Stale plans and newly started experiments are refused.

Verified twice

Through the Admin API, and with flagsmith eval --test, which shows what an SDK actually resolves.

What the graph looks at

Every read uses the CLI's built-in --json --jq, so there's no jq, Python or Node, and the agent reads one short report.

Undo, with zero tokens

Every apply commits a journal record. Rolling back never needs an agent.

  • Plain script: undo.sh last or a change id.
  • Plain git: git revert the flag-change commit, and the post-commit hook offers to restore Flagsmith.
  • Drift-safe: refuses to overwrite a change someone else made since.
  • Experiment-safe: refuses while an experiment runs on the flag.
  • Survives the revert: reads the record back from git history.

Install

Needs the Flagsmith CLI v2+, git and bash (Git Bash on Windows). gh is optional.

  • Follows the open Agent Skills spec, validated in CI with skills-ref.
  • 22 end-to-end checks against Flagsmith Cloud, covering every risk level, every guard, apply, undo and revert.
  • A demo project seed with a sample app that exercises every branch.
your repo
# 1. add the skill to your agent
mkdir -p .claude/skills
cp -R skills/flagsmith-change-plan .claude/skills/

# 2. log in and bind the repo
flagsmith login
flagsmith init

# 3. optional: git revert → undo offer
bash .claude/skills/flagsmith-change-plan/scripts/install-hooks.sh

# then just ask your agent:
"Turn off new_checkout in Production."
